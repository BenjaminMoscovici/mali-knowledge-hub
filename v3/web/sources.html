How to read this catalogue

Loaded is not unlimited

Loaded datasets have evidence rows in this release. Counts are source rows or extracted facts, not unique projects, people reached or organisations. Some sources overlap.

Connected is not a freshness check

Other connected sources are listed from integration records. This page does not run every connector or verify the latest provider release. Missing dates are shown explicitly.

Registered is not integrated

Sources awaiting evidence, access or qualification cannot yet support answers. New feeds submitted through Administration stay there for connector review until integrated.

Evidence varies by question

This is a catalogue of the Hub’s coverage, not a guarantee for any particular question. Inspect the citations in each answer. The language model itself is not a source.
