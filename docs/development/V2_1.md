## Heterogeneous registry research

Development revisions `b384c4e` and `f1613d7` build on `4512eaf`. The live services and corpus were left untouched.

The registry previously handled exact annual observations, while document, humanitarian and financing retrieval still travelled through separate hardcoded workers. The new path identifies a reviewed capability from a source name or dated topic and reads the pinned release through an adapter. This cycle qualified the original RGPH5 PDF pages, HPC HNO national observations and the FTS export. Each result retains the release, source link, reference period, geographic scope and page or row locator. Mappings declare the fields that can be shown and any localized search terms. The source catalogue exposes only the useful search terms. It does not expose file paths, mappings or release internals.

Named requests and dated registered topics can contribute these records to the ordinary research ledger. The existing workers still run under their existing rules and take precedence when the same record is already present. A separate explicit evidence-brief route uses the same retrieval functions and serves original excerpts and structured figures without model calls. Its year-only follow-ups preserve sources and exact plan IDs. Retrieval filters out unrelated plan IDs and years, and refuses to turn a national release into a cercle or commune estimate when the requested administrative level is explicit.

The financing gap is a deterministic subtraction of two numbers from the same plan/year record, with the source currency and input labels retained. The model route also checks numeric witnesses for supported citation syntax on claims cited only to registry sources. A valid ID with an absent or wrong-sign quantity no longer passes that guard. This check does not establish sentence-level entailment, unit equivalence or support for qualitative claims.
