# Independent Work evaluation

The comparison is between the existing [V4 test application](https://mali-knowledge-hub-v4-test.onrender.com/) and the isolated V2.1 evaluation service. Use the preview link only after the operator has verified its model and corpus access. Keep the deployed revisions fixed for the review.

V2.1 adds registry-driven discovery to ordinary chat, more precise document and record targeting, tighter geographic and temporal scope, and checks for unsupported quantities. Some simple answers remain deterministic. The comparison should cover the normal guest chat experience at the same analysis depth on both services.

## Review protocol

- Start fresh guest conversations on each build and use the same questions, analysis depth and follow-up sequence. Choose the questions independently. Keep the complete set of attempts, including errors, slow responses and evidence gaps.
- Cover demography and administrative ambiguity, humanitarian needs and operations, projects, financing, and cross-source briefing tasks. Include French and English, one question with a missing evidence layer, and follow-ups that change geography or year while retaining the rest of the scope.
- Inspect the original source for material claims. Distinguish answer accuracy, completeness, analytical quality, professional usefulness, natural communication, conversation continuity, citation accuracy, and ease of verification.
- Record what you could use in a briefing as written, what you had to verify or rewrite, and what you could not establish. Retain the exact prompt and any follow-ups. Report correctness and usefulness ahead of latency and cost.
- Exercise the ordinary chat interface and inline citation drawer. Record whether the linked passage or source row supports the material finding. Use public professional scenarios and keep private notes outside the product.

The preview uses reviewer access at the browser gate, then ordinary guest chat inside the application. The operator should convey access credentials separately. Account features are disabled while evaluating. Free hosting can introduce a cold start. An imported release's reference period and retrieval date have different meanings.

No expected answers or selected successful demonstrations are included. The benchmark and held-out cases remain unchanged.
